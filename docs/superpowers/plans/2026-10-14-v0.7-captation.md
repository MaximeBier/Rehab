# v0.6.2 / v0.7.0 — Overlay paysage et captation fiable — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rendre l'écran de blocage utilisable en paysage (0.6.2), puis compter et bloquer tout Instagram et tout X sauf les DM, de façon robuste (0.7.0).

**Architecture:** Lot 1 restructure `BlockOverlay` en blocs réutilisés par une mise en page portrait (inchangée) et paysage (deux colonnes défilantes). Lot 2 : le module `rules` ignore les nœuds invisibles et reconnaît les DM par des conteneurs couvrant l'écran ; Instagram passe en « tout sauf DM » comme X ; le service choisit la fenêtre de l'app parmi toutes les fenêtres, traite un arbre illisible comme la cible (échec fermé) et garde son ticker tant que l'app est à l'écran ; le mode dégradé « écran inconnu » disparaît ; l'écran Debug compare le temps Android au temps compté.

**Tech Stack:** Kotlin 2.4.20, Jetpack Compose (overlay et UI), AccessibilityService, Room, UsageStatsManager, JUnit 5 (`rules`, `domain`), JUnit 4 + Robolectric (`app`).

**Spec:** `docs/superpowers/specs/2026-10-14-v0.7-captation-design.md`

- Règle produit : en cas de doute, l'écran **compte**. Un faux DM est une fuite (interdit), un DM compté est acceptable.

## Review Focus

1. Écran X ou Instagram dont l'arbre contient un conteneur DM **invisible** (écran Messages gardé en mémoire) → doit compter. Test : tâche 2 (`InvisibleDmRegressionTest`).
2. Fenêtre de l'app présente mais racine illisible (transition, vidéo plein écran) → doit compter, pas « sortie ». Test : tâche 5 (`unreadable snapshot`, `WindowPickerTest` racine nulle connue).
3. Vidéo regardée sans toucher, puis quota atteint → le blocage doit tomber sans événement d'accessibilité (ticker actif tant que l'app est à l'écran, DM compris). Couvert par revue de code tâche 5 + checklist Pixel tâche 9.
4. Un petit élément DM (vignette « Messages », aperçu de conversation dans le fil) ne doit pas faire classer l'écran en DM. Test : tâche 3 (`petit conteneur dm ne suffit pas`).
5. Paysage avec police système à 130 % ou fenêtre basse (écran partagé) → bouton d'appui et « Quitter » atteignables (défilement). Rendu : tâche 1 (`overlay-paysage-130`, `overlay-paysage-bas`).

`Snapshot.kt`, dans `Bounds` :

```kotlin
    val width: Int get() = right - left
```

`Matcher.kt`, après `NearBottom` :

```kotlin
    /**
     * Le nœud couvre au moins [minFraction] de la surface de la racine (profondeur 0, voir [NearBottom] pour ce
     * choix). Sert aux DM (v0.7.0) : un conteneur de conversation qui occupe l'écran est un DM ; le même
     * identifiant sur un petit aperçu ailleurs ne l'est pas. Sans racine : `false`.
     */
    data class CoversScreen(val minFraction: Double = 0.5) : Matcher {
        override fun matches(node: Node, all: List<Node>): Boolean {
            val rootArea = all.firstOrNull { it.depth == 0 }?.bounds?.area ?: return false
            if (rootArea <= 0) return false
            return node.bounds.area >= minFraction * rootArea
        }
    }
```

```kotlin
package rehab.app.service

/**
 * Descripteur d'une fenêtre à l'écran, extrait d'`AccessibilityWindowInfo` pour choisir sans Android.
 * [packageName] est nul quand la racine de la fenêtre est illisible (transition, vidéo plein écran).
 */
data class WindowCandidate(
    val windowId: Int,
    val isApplication: Boolean,
    val packageName: String?,
    val active: Boolean,
    val focused: Boolean,
    val area: Long,
)

data class PickedWindow(val windowId: Int, val packageName: String)

/**
 * v0.7.0 : `rootInActiveWindow` seul ratait l'app quand la fenêtre active était ailleurs (écran partagé, PiP) ou
 * momentanément illisible — le service croyait alors qu'on avait quitté l'app et arrêtait son ticker. On regarde
 * toutes les fenêtres d'application : l'active si elle est suivie, sinon la focalisée, sinon la plus grande.
 * Une fenêtre à racine illisible garde le paquet vu précédemment pour son `windowId` ([lastKnown]).
 */
object WindowPicker {
    fun pick(windows: List<WindowCandidate>, tracked: Set<String>, lastKnown: Map<Int, String>): PickedWindow? {
        val apps = windows.filter { it.isApplication }
            .mapNotNull { w -> (w.packageName ?: lastKnown[w.windowId])?.takeIf { it in tracked }?.let { w to it } }
        val chosen = apps.firstOrNull { it.first.active }
            ?: apps.firstOrNull { it.first.focused }
            ?: apps.maxByOrNull { it.first.area }
            ?: return null
        return PickedWindow(chosen.first.windowId, chosen.second)
    }
}
```

```kotlin
package rehab.rules

/**
 * Anonymise une capture avant commit (dépôt public, v0.7.0) : tout `text`/`contentDesc` devient un jeton neutre
 * (`t<i>`/`d<i>`, i = index du nœud), sauf les libellés d'interface dont dépendent les règles ([KEEP]) et les
 * chaînes vides. Identifiants, classes, bounds, sélection et profondeur sont conservés : c'est ce que lisent les règles.
 */
object CaptureAnonymizer {
    val KEEP = Regex(
        "^(Accueil|Home|Messages|Direct|Envoyer un message|Reels|Rechercher|Search|Recherche|Explorer|Explore|Profil|Profile|Notifications|Suivre|Follow|Suggestions?|Pour vous|For you|Abonnements|Following)$",
        RegexOption.IGNORE_CASE,
    )

    fun anonymize(snapshot: Snapshot): Snapshot = snapshot.copy(
        nodes = snapshot.nodes.mapIndexed { i, n ->
            n.copy(text = n.text?.let { mask(it, "t$i") }, contentDesc = n.contentDesc?.let { mask(it, "d$i") })
        },
    )

    private fun mask(value: String, token: String) = if (value.isBlank() || KEEP.matches(value.trim())) value else token
}
```
