# v0.4.0 — Onglet Stats (avant / après Rehab)

Date : 2026-09-23. Demande de Maxime : « renseigner le temps moyen d'utilisation des applications dans les settings, pour faire des stats avant/après ; nouvel onglet stats, rien de ouf pour l'instant ». Choix validé : historique Android + saisie manuelle ; barre à 5 onglets (Accueil, Réglages, Journal, Stats, Debug).

## Sources

- **Avant Rehab (Android)** : `UsageStatsManager.queryUsageStats(INTERVAL_BEST, installedAt − 28 j, installedAt)` par app (Instagram, X), somme de `totalTimeInForeground` ÷ nombre de jours réellement couverts (bornes des buckets retournés, au plus 28 ; 0 jour couvert → « indisponible »). `installedAt` = `graph.streakRecord.installedAt()`. Temps **app entière** (DM compris).
- **Avant Rehab (manuel)** : saisie en minutes/jour par app dans les Réglages ; si renseignée, elle remplace la valeur Android pour la comparaison.
- **Maintenant (Android)** : même calcul sur les 7 derniers jours (app entière) — comparable à l'« avant » Android.
- **Maintenant (Rehab)** : temps mesuré par Rehab sur les cibles (fil, Reels) sur les 7 derniers jours complets + aujourd'hui, depuis `usageLog` ; moyenne par jour.
- Permission : `android.permission.PACKAGE_USAGE_STATS` (déclarée, `tools:ignore="ProtectedPermissions"`), accordée par l'utilisateur via `Settings.ACTION_USAGE_ACCESS_SETTINGS` ; vérifiée par `AppOpsManager.unsafeCheckOpNoThrow(OPSTR_GET_USAGE_STATS, …)`. Sans permission : les valeurs Android affichent « accès requis » et un bandeau « Autoriser l'accès aux données d'utilisation » avec action OUVRIR.

## Écran Stats (même langage visuel, pas de graphique)

- En-tête `REHAB` + légende « 7 derniers jours ».
- Par app, une carte : titre (« Instagram »), lignes clé/valeur : « Avant Rehab » (`45 min/j` + mention « Android » ou « saisi »), « Maintenant » (`12 min/j`, Android, app entière), « Dont fil et Reels » (mesure Rehab), et une ligne « Écart » (`−73 %` en `accent` si baisse, `danger` si hausse, « — » si l'avant est inconnu).
- Bloc « Total » (Instagram + X) de même forme.
- Note : « Avant = moyenne des 28 jours précédant l'installation (historique Android, ou ta saisie). Maintenant = moyenne des 7 derniers jours. »

## Réglages

Section « AVANT REHAB » : une ligne par app, valeur `45 min/j` (saisie) ou `38 min/j · Android` (auto) ou « à renseigner » ; dialogue numérique (minutes/jour, vide = revenir à la valeur Android). Stockage app (SharedPreferences `rehab_stats`), pas de verrou (ne desserre rien).

## Technique

- Calculs purs testables (`app/.../stats/StatsMath.kt`) : moyenne par jour à partir de buckets (début, fin, durée) avec jours couverts ; écart en % arrondi ; formatage (`HomeText.duration`).
- Lecture `UsageStatsManager` derrière une interface (`UsageHistory`) pour tester sans Android ; implémentation Android dans `app/.../stats/AndroidUsageHistory.kt`. Tout sur `Dispatchers.IO` via `RehabViewModel`.
- Navigation : `Tab` gagne `Stats` entre Journal et Debug ; libellés d'onglet vérifiés à 130 % (rendu `components-navbar-130`), espacement réduit si nécessaire.
- Rendus PNG : `stats` (valeurs réalistes), `stats-sans-acces`.

## Tests

StatsMath (jours couverts, bucket partiel, zéro jour, écart hausse/baisse/inconnu), sélection manuel > Android, formatage ; rendu de la barre à 5 onglets à 100 % et 130 %.
